# Contributing

Thanks for contributing.

- **Sign off every commit** with `git commit -s` (the
  [Developer Certificate of Origin](https://developercertificate.org/)).
- Run `gofmt -w .`, `go vet ./...` and `go test ./...` before opening a PR.
- Keep PRs small and focused.
- Changes to command execution (`cmd/agent.go`), authentication or crypto get extra
  review — expect questions.

By contributing you agree your code is licensed under Apache-2.0.
